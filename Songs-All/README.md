# Songs-All
Information Visualization Project for 5th year at Polytech Nice Sophia.

## To get the data
Execute the following scripts
- data_scripts.py
- additional_scripts.py

## To run the python webserver (to get bubble chart data)
Navigate into the backend folder, install the requirements and execute app.py.
```
cd .\backend\
pip install -r requirements.txt
python app.py
```
The python webserver will run in the background on port 3000.
